⚡ Metodología Extreme Programming (XP)

Este proyecto fue diseñado siguiendo las prácticas esenciales de XP:

🧪

TDD (Pruebas Unitarias)

Suite completa en carpeta Unitest/ con 46 pruebas en archivos .py_test que garantizan cálculo de totales, stock y cupones.

📦

Entregas Pequeñas

Incrementos funcionales iterativos con catálogo, carrito dinámico, descuentos y checkout.

👥

Programación en Parejas

Trabajo colaborativo documentado con rotación de roles (Cliente, Coach, Tracker, Programadores).

🔄

Integración Continua

Flujo automatizado con GitHub Actions (.github/workflows/ci.yml) para validación de código.
