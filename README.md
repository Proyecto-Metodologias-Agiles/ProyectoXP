#  Carrito de Compras - Proyecto Metodologías Ágiles (XP)

## Ejecución de Pruebas Unitarias (TDD)

Para ejecutar pruebas unitarias automáticas:

```bash
python run_tests.py
```

Para ejecutar pruebas individuales:

```bash
python Unitest/productos.py_test
python Unitest/carrito.py_test
python Unitest/descuentos.py_test
```

---

##  Iniciar la Interfaz Web Visual

Para levantar el servidor local y abrir la tienda en tu navegador:

```bash
python server.py
```

O abrir directamente abriendo el navegador:
```bash
python server.py --open
```
Luego visita: [http://localhost:8000](http://localhost:8000)
